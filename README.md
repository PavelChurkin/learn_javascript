# Учебный Курс по JavaScript

Полный учебный курс по языку программирования JavaScript с примерами кода, охватывающий базовую теорию и практические примеры.

## 📚 Структура Курса

### [Модуль 1: Основы JavaScript](course/module1-basics/)

Введение в базовые концепции языка.

- **01-variables.js** - Переменные (var, let, const), область видимости, hoisting
- **02-data-types.js** - Типы данных (number, string, boolean, null, undefined, symbol, object)
- **03-operators.js** - Операторы (арифметические, логические, сравнения, присваивания)
- **04-type-conversion.js** - Преобразование типов (явное и неявное)

### [Модуль 2: Управляющие Конструкции](course/module2-control-structures/)

Управление потоком выполнения программы.

- **01-conditionals.js** - Условные операторы (if, else, switch, тернарный оператор)
- **02-loops.js** - Циклы (for, while, do-while)
- **03-loop-control.js** - Управление циклами (break, continue, метки)
- **04-advanced-loops.js** - Специальные циклы (for...in, for...of)

### [Модуль 3: Функции](course/module3-functions/)

Создание переиспользуемых блоков кода.

- **01-function-basics.js** - Основы функций (объявление, параметры, return)
- **02-function-types.js** - Типы функций (declaration, expression, arrow functions)
- **03-scope-closure.js** - Область видимости и замыкания
- **04-advanced-functions.js** - Продвинутые концепции (callback, IIFE, рекурсия)

### [Модуль 4: Массивы и Объекты](course/module4-arrays-objects/)

Работа со структурами данных.

- **01-arrays.js** - Массивы (создание, методы, перебор)
- **02-array-methods.js** - Методы массивов (map, filter, reduce)
- **03-objects.js** - Объекты (создание, свойства, методы)
- **04-json.js** - JSON и работа с данными

### [Советы по Производительности](course/performance-tips/)

Рекомендации по оптимизации кода и повышению скорости выполнения скриптов.

## 🚀 Быстрый Старт

### Требования

- **Node.js** (версия 14 или выше) для запуска примеров в консоли
- Любой современный браузер для запуска в веб-окружении

### Запуск Примеров

#### Вариант 1: Node.js

```bash
# Запуск конкретного модуля
node course/module1-basics/01-variables.js

# Запуск всех примеров модуля
node course/module1-basics/01-variables.js
node course/module1-basics/02-data-types.js
node course/module1-basics/03-operators.js
node course/module1-basics/04-type-conversion.js
```

#### Вариант 2: Браузер

Создайте HTML-файл:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>JavaScript Course</title>
</head>
<body>
    <h1>JavaScript Course</h1>
    <p>Откройте консоль браузера (F12) для просмотра результатов</p>

    <!-- Подключите нужный файл -->
    <script src="course/module1-basics/01-variables.js"></script>
</body>
</html>
```

## 📖 Особенности Курса

### ✅ Подробные Комментарии

Каждая строка кода снабжена комментариями, объясняющими её назначение:

```javascript
// Объявление переменной с использованием let
let modernVariable = "Я переменная let";

// let имеет блочную область видимости
let blockScopedVariable = "Внешняя область";

// Можно изменить значение
blockScopedVariable = "Изменённое значение";
```

### ✅ Модульная Структура

Курс разбит на независимые модули, которые можно изучать в любом порядке (рекомендуется последовательное изучение).

### ✅ Практические Примеры

Все примеры можно запускать и экспериментировать с кодом:

```javascript
// Практический пример: валидация email
function isValidEmail(email) {
  return email.includes("@") && email.includes(".");
}

console.log(isValidEmail("user@example.com")); // true
console.log(isValidEmail("invalid-email")); // false
```

- Async/await
