# Модуль 1: Основы JavaScript

## Введение

JavaScript — это высокоуровневый интерпретируемый язык программирования, который используется для создания интерактивных веб-страниц и приложений.

## Содержание модуля

1. **01-variables.js** - Переменные и их объявление
2. **02-data-types.js** - Типы данных в JavaScript
3. **03-operators.js** - Операторы (арифметические, логические, сравнения)
4. **04-type-conversion.js** - Преобразование типов

## Как запустить примеры

Каждый файл можно запустить отдельно с помощью Node.js:

```bash
node course/module1-basics/01-variables.js
node course/module1-basics/02-data-types.js
node course/module1-basics/03-operators.js
node course/module1-basics/04-type-conversion.js
```

Или в браузере, подключив файл в HTML:

```html
<script src="course/module1-basics/01-variables.js"></script>
```
