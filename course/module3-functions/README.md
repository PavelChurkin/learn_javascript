# Модуль 3: Функции

## Описание

Функции — это переиспользуемые блоки кода, которые выполняют определённую задачу. Они являются одним из фундаментальных строительных блоков в JavaScript.

## Содержание модуля

1. **01-function-basics.js** - Основы функций (объявление, вызов, параметры, возврат значений)
2. **02-function-types.js** - Типы функций (function declaration, expression, arrow functions)
3. **03-scope-closure.js** - Область видимости и замыкания
4. **04-advanced-functions.js** - Продвинутые концепции (callback, IIFE, рекурсия)

## Как запустить примеры

```bash
node course/module3-functions/01-function-basics.js
node course/module3-functions/02-function-types.js
node course/module3-functions/03-scope-closure.js
node course/module3-functions/04-advanced-functions.js
```
