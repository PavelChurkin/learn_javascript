# Модуль 4: Массивы и Объекты

## Описание

Массивы и объекты - это структуры данных для хранения коллекций значений. Массивы используются для упорядоченных списков, а объекты - для хранения пар ключ-значение.

## Содержание модуля

1. **01-arrays.js** - Массивы: создание, методы, перебор
2. **02-array-methods.js** - Методы массивов (map, filter, reduce и др.)
3. **03-objects.js** - Объекты: создание, свойства, методы
4. **04-json.js** - JSON и работа с данными

## Как запустить примеры

```bash
node course/module4-arrays-objects/01-arrays.js
node course/module4-arrays-objects/02-array-methods.js
node course/module4-arrays-objects/03-objects.js
node course/module4-arrays-objects/04-json.js
```
