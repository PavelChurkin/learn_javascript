# Модуль 2: Управляющие конструкции

## Описание

Управляющие конструкции позволяют контролировать поток выполнения программы: принимать решения (условия) и повторять действия (циклы).

## Содержание модуля

1. **01-conditionals.js** - Условные операторы (if, else, else if, switch)
2. **02-loops.js** - Циклы (for, while, do-while)
3. **03-loop-control.js** - Управление циклами (break, continue)
4. **04-advanced-loops.js** - Специальные циклы (for...in, for...of)

## Как запустить примеры

```bash
node course/module2-control-structures/01-conditionals.js
node course/module2-control-structures/02-loops.js
node course/module2-control-structures/03-loop-control.js
node course/module2-control-structures/04-advanced-loops.js
```
